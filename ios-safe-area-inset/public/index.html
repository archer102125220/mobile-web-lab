iOS 虛擬鍵盤與 Safe Area 互動測試

點擊以下輸入框喚醒 iOS 虛擬鍵盤。在 iOS Safari 中，當鍵盤彈出時，visualViewport 會縮小，且 env(safe-area-inset-bottom) 可能會動態變為 0px。

標準 CSS 實作寫法與相容性

1. 必須的 HTML Meta 標籤

<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">

2. 包含 iOS 11 (constant) 相容性的 CSS 寫法

/* 頂部避讓 (Navigation Bar) */
.header {
  padding-top: constant(safe-area-inset-top); /* iOS 11.0 - 11.2 */
  padding-top: env(safe-area-inset-top);      /* iOS 11.2+ */
}

/* 底部避讓 (Tab Bar / Footer) */
.footer {
  padding-bottom: constant(safe-area-inset-bottom);
  padding-bottom: env(safe-area-inset-bottom);
}

/* 左右側避讓 (橫向 Landscape 模式) */
.body-container {
  padding-left: env(safe-area-inset-left);
  padding-right: env(safe-area-inset-right);
}

3. 浮動按鈕 (FAB) 的 calc() 組合技巧

.floating-action-button {
  position: fixed;
  right: calc(16px + env(safe-area-inset-right));
  bottom: calc(16px + env(safe-area-inset-bottom));
}

4. Tailwind CSS 寫法 (Arbitrary Values)

<!-- 頂部與底部避讓 -->
<header class="pt-[env(safe-area-inset-top)]">...</header>
<footer class="pb-[env(safe-area-inset-bottom)]">...</footer>

<!-- 浮動按鈕 -->
<button class="fixed right-4 bottom-[calc(1rem+env(safe-area-inset-bottom))]">+</button>
